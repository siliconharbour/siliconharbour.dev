# API

The JSON API provides read-only access to community data without authentication and supports cross-origin requests.

## Base URL

## Pagination

List endpoints support pagination:

- `limit` - Number of items (default: 20, max: 100)
- `offset` - Items to skip (default: 0)

Responses include a `pagination` object:

```json
{
  "data": [...],
  "pagination": {
    "total": 42,
    "limit": 20,
    "offset": 0,
    "hasMore": true
  }
}
```

Responses also include [RFC 5988](https://tools.ietf.org/html/rfc5988) `Link` headers for navigation:

```
Link: <https://siliconharbour.dev/api/companies?limit=20&offset=20>; rel="next",
      <https://siliconharbour.dev/api/companies?limit=20&offset=0>; rel="first"
```

## MCP server

AI assistants and agents can connect to the [MCP (Model Context Protocol)](https://modelcontextprotocol.io) server at `/mcp`.

**Endpoint:** `https://siliconharbour.dev/mcp`

### Tools

The server has two public tools and one authenticated tool. Expand a tool to see its available functions. This list comes from the bridge implementation and stays in sync with the server.

<MCPTools />


### Connect an MCP client

Add the endpoint to any client that supports remote MCP servers:

```json
{
  "mcpServers": {
    "siliconharbour": {
      "url": "https://siliconharbour.dev/mcp"
    }
  }
}
```

You can use `search` and `query` without signing in. These tools provide read-only access to public SiliconHarbour data.

OAuth is optional. To use the `execute` tool, start your MCP client's sign-in action and log in with your SiliconHarbour account. The client discovers the OAuth endpoints automatically and opens the site's login and consent flow. You do not need an API key or shared secret.

The `execute` tool requires the `mcp:write` OAuth scope and an administrator account. It can run imports, create or update records, and perform review actions. An invalid or expired OAuth session is rejected instead of falling back to public access.

### Example queries

```js
// Upcoming events
import { events } from "siliconharbour";
export default await events({ upcoming: true, limit: 5 });
```

```js
// Jobs filtered by keyword
import { jobs } from "siliconharbour";
export default await jobs({ query: "developer", limit: 10 });
```

```js
// Cross-entity query
import { events, companies, groups } from "siliconharbour";
const [upcoming, cos, grps] = await Promise.all([
  events({ upcoming: true }),
  companies({ limit: 5 }),
  groups({ limit: 5 }),
]);
export default {
  upcoming: upcoming.length,
  companies: cos.map((c) => c.name),
  groups: grps.map((g) => g.name),
};
```

## Feeds

RSS feeds and an iCal calendar are also available. See [Stay Connected](/stay-connected) for details.

- `/feed.rss` - Combined RSS feed
- `/events.rss` - Events RSS feed
- `/news.rss` - News RSS feed
- `/jobs.rss` - Jobs RSS feed
- `/calendar.ics` - iCal calendar subscription
